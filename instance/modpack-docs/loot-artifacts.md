# Лут с боссов и артефакты

Дата: 2026-11-06. Цель: **сложный бой = награда, которой радуешься**. Никакой «картошки с ниткой».
Источник: лут-таблицы из jar установленных модов + Modrinth (NeoForge 1.21.1).

## 📌 Решения (2026-11-06)

- **Главное правило:** после 30-минутного боя игрок **не должен пожалеть**. С каждого босса падает **что-то уникальное, только с него**, и это реально полезно. Никакого мусора.
- «Ключи тира» — **пока не делаем**.
- Lootr — ❌ не ставим.
- ✅ **Artifacts** и ✅ **Relics** (+ OctoLib) — установлены; их предметы добавляем в дроп боссов.
- ✅ **Apotheosis** — установлен (2026-11-06). Apothic Spawners пришлось поставить (жёсткая зависимость), но модификаторы спавнеров отключены KubeJS-скриптом.

## 🎯 План: уникальный дроп с каждого босса

✅ **Реализовано (2026-11-06):** `kubejs/server_scripts/balance_boss_loot.js` — таблица ниже, с правками: Phase Sphere и элитры заменены, Helium Flamingo не используется. Эксклюзивность (убрать эти предметы из сундуков) **ещё не сделана**.

**Принцип «эксклюзив»:** часть предметов Artifacts/Relics **убираем из сундуков и мимиков** и закрепляем за конкретным боссом (LootJS). Тогда предмет — трофей этого босса: «Сапоги Фростмо — только с Frostmaw».

Каждый босс гарантированно даёт:
1. Свой родной уникальный дроп (если он хороший — оставляем, если слабый — усиливаем).
2. **Эксклюзивный артефакт/реликвию по теме босса** (100%).
3. Бонус: шанс на второй артефакт/реликвию из пула своего тира, опыт, редкие материалы.
4. Каждому игроку — свой мешок (MultiplayerBosses).
Мусор (кости, уголь, гнилая плоть, камень, золотой меч) — удаляем.

## 2. Как устроим награду с босса

Каждый босс даёт 4 слоя:
1. **Сигнатурный дроп мода** — оставляем (это их уникальные предметы).
2. **Ключ тира** — предмет прогрессии (см. `balance.md`, раздел 1), только с этого босса.
3. **Бонусный пул по тиру босса** (LootJS):
   - мини-босс: 1 случайный артефакт обычной/редкой редкости **или** снаряжение с аффиксом;
   - мидл-босс: гарантированно 1 редкий+ артефакт/реликвия + 1 предмет с аффиксом + гем;
   - финальный: 1 эпический/легендарный + 2 предмета с аффиксами + материалы высшего тира.
4. **Каждому игроку свой мешок** — MultiplayerBosses (уже стоит).

Правила:
- **Убрать мусор** из таблиц боссов (кости, уголь, гнилая плоть, камень) — LootJS.
- **Нет повтора бесполезного:** уникальные артефакты — разными пулами по тиру, чтобы не выпадало одно и то же.
- Боссы в **дальних измерениях** (космос, Энд, Twilight) — лучшие пулы.
- Лучшие модули оружия Gunsmithing и детали T5–T6 — только с боссов.

## 4. Мой совет

**Набор:** Lootr + Artifacts + Relics + Apotheosis (без Apothic Spawners).
- Artifacts — «находки» в сундуках и с мимиков.
- Relics — долгосрочные прокачиваемые предметы.
- Apotheosis — редкость и аффиксы на оружии/броне, гемы — основной «рад дропу».
- Lootr — чтобы всем досталось.

**Затем:**
1. LootJS: бонусные пулы по тиру боссов (раздел 2), убрать мусор.
2. Проверить сильные мобильные предметы Artifacts/Relics (бег по воде, полёт, рывки) — не должны заменить корабли.
3. Поднять HP боссов с учётом силы, которую дают аффиксы.

**Альтернатива поменьше:** Lootr + Artifacts + Relics (без Apotheosis) — меньше силы игрока, проще баланс, но меньше «случайно крутого» дропа.
