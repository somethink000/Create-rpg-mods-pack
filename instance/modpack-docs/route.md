# Маршрут экспедиции — черновик

Черновик 2026-11-17, на согласование. Источник: структуры и шаблоны из jar модов сборки (732 структуры), тиры из [balance.md](balance.md), боссы из [mobs-bosses.md](mobs-bosses.md).

## Решения (2026-11-17)
- **Строго по одному:** в книге всегда одна текущая цель; следующий данж открывается только после прохождения текущего.
- **Место дракона и порядок боссов** — по силе боссов и мобов и по связи с прогрессией Create. Решаем после разбора лута (этап 3) и характеристик боссов.
- Следующий шаг — лут по тирам, потом книга.
- **Данжи маршрута появляются только когда их открывает книга.** В обычной генерации мира они отключены. Когда этап открывается, скрипт ставит его структуру далеко от игрока (дальше с каждым тиром, ~1500–4000 блоков — чтобы лететь на Aeronautics) в подходящем биоме и регистрирует её в мире как настоящую структуру (её видят гарнизоны; `/locate` — нет, он проверяет только сетку естественной генерации, поэтому координаты даёт книга). Проверено по коду игры: постановка структуры не зависит от биома; нужны только загруженные чанки — скрипт загружает их сам. Ограничение: у поставленной так структуры нет подгонки рельефа (может немного висеть или врезаться в склон).
- **Попутные данжи** (все остальные, включая When Dungeons Arise) **не вырезаем**, а разносим далеко друг от друга, чтобы между ними летать. Лут в них — по тиру.
- **Лут — вокруг Create:** ресурсов в 3–5 раз меньше, с лимитом по тиру (алмазы не раньше T2, незерит не раньше T4); вместо них детали Create своего тира — лут ускоряет производство, но не заменяет его. Уникальные детали — только у боссов маршрута.

## Идея
Все данжи сборки делятся на два вида:
- **Этапы маршрута** (~25): данжи с боссами и большие крепости. Идут по порядку, каждый — следующий шаг тиров T0–T6.
- **Попутные структуры** (остальные ~700: Moog's, Dungeons and Taverns, Towns and Towers, Structory, YUNG's и т. д.): встречаются по дороге, лут в них — по тиру (этап 3 плана), в книгу не входят.

## Как это работает в игре
1. **Журнал экспедиции** — книга Patchouli (мод уже стоит), выдаётся при первом входе. Каждый этап — страница: что за место, какие враги и босс, что взять с собой (какой корабль), что даст награда.
2. Страница следующего этапа **открывается, когда пройден предыдущий**. Patchouli умеет прятать страницы до получения достижения; достижение выдаёт скрипт.
3. **Этап пройден**, когда убит его босс, а у этапа без босса — когда зачищен гарнизон. Засчитывается всем игрокам рядом (игра компанией).
4. **Куда лететь:** при открытии этапа игрок получает **карту экспедиции** — ванильную карту исследователя, которая указывает на ближайшую структуру этого этапа. Для этапов в Незере и Энде карта выдаётся при входе в это измерение.
5. Награды этапов — материалы для рецептов следующего тира Create (этап 5 плана). Так маршрут и прогрессия Create связаны.

### Боковые ветки (по желанию, в книге отдельными главами)
- **Twilight Forest** — своя цепочка боссов (Naga → Lich → Hydra → Ur-Ghast → Snow Queen…), с T2.
- **The Aether + Deep Aether** — небесные данжи (бронзовый: Slider, серебряный: Valkyrie Queen, золотой: Sun Spirit), с T3: туда удобно на кораблях.
- **Deeper and Darker** — Древний храм в Otherside, с T4.
- Остальные боссы Legendary Monsters, Bosses'Rise, Mowzie's (Frostmaw, Umvuthi, Sandworm, Infernal Dragon, Yeti, Lava Eater, Cloud Golem, Possessed Paladin…) — «охота» в книге: необязательные, с хорошей наградой.

## Что проверено, а что нет
- **По шаблонам структур в jar** (сущность стоит в самой структуре): этапы 5, 6, 9, 20, 24 и данжи Aether.
- Боссы Cataclysm (8, 14–16, 18, 21–23) — шаблоны в jar названы по боссам; какой шаблон в какой структуре — по описанию мода.
- **По описаниям модов, в шаблонах не найдены** (босс вызывается иначе): Mowzie's (3), Aquamirae (11), Kraken (12 — в шаблоне только его пушки), BoMD (25). Небесный кит (13) — босса не нашёл, поставил как гарнизон.
- Измерения — по тегам биомов из jar.
- Лут данжей ещё не разобран — это этап 3. По нему порядок может сдвинуться.
