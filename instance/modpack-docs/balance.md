# План баланса

Дата: 2026-11-06. Статус: **план согласован** (2026-11-06), применяем по порядку из раздела 15. Применённое помечаем ✅.

**Решения по плану:**
- Physics Assembler — **рецепт оставляем** как есть.
- Порох — **все рецепты оставляем**. Дороже делаем то, что из него собирается: патроны, гильзы, снаряды.
- Остальной план — согласован.
- Важно: лут с боссов должен **радовать** — сложный бой = крутая награда (см. `loot-artifacts.md`).
Опора: конфиги в `config/` (значения ниже — реальные текущие), рецепты из jar, решения из `decisions.md`.

## 0. Принципы

1. **Ничего даром.** Любая энергия, ресурс, движение или урон стоят ресурсов/топлива. (Уже: ✅ вагонетки, ✅ генераторы камня, ✅ одна сталь, ✅ один FE-путь, ✅ конечная вода, ✅ поезда на топливе, ✅ Picky Wheels, ✅ Low-Heated.)
2. **Путешествие = прогресс.** Ключевые компоненты — только из конкретных мест, боссов или измерений. Сидя на базе, следующий тир не открыть.
3. **Тиры, а не стены.** Каждый этап открывает новую технику, которая нужна для следующего этапа (корабль → дальше → лут → лучше корабль).
4. **Сила игрока растёт медленнее, чем сила мира.** Remnants делает мир опаснее с дистанцией; боссы масштабируются от числа игроков.
5. **Одна система на одну задачу.** Одна сталь, одна электрика, один основной путь получения пороха и т.д. — чтобы дорогие рецепты нельзя было обойти соседним модом.
6. **Длительность:** ~7–14 дней игры компанией. Ориентир — 1 тир ≈ 1–2 вечера.
7. **Проверяем цифры тестом**, а не на глаз (раздел 14).

### 7.3 Пушки против боссов — главный риск
Big Cannons и ракеты могут убить босса за секунды. Варианты:
1. **Лимит урона за удар** для боссов (например не больше 5–8% HP за попадание) — KubeJS `EntityEvents` (проверить, можно ли менять урон в 2101) или в нашем мини-моде.
2. **Сопротивление взрывам** для боссов (тег/атрибут) — снаряды и ракеты наносят ×0.3.
3. Арены боссов **в местах, куда корабль с пушками не подлетит** (подземелья, данжи) — уже часто так.
Предлагаю 1 + 2.

## 14. Как проверяем баланс
1. **Тестовый мир** (копия, креатив/выживание): для каждого тира собрать «типовое снаряжение» и засечь время боя с боссами этого тира.
2. **Стоимость в ресурсах:** для ключевых предметов (корабль T2, ракета T5, гатлинг, 64 патрона) посчитать итоговые ресурсы по JEI.
3. **Тест «без путешествий»:** попытаться дойти до T3, не уходя дальше 500 блоков. Если получилось — где-то дыра.
4. **FPS/TPS:** spark-профиль на заводе + корабле.
5. После правок — пересобираем `defaultconfigs/`, чтобы настройки шли в каждый новый мир и на сервер.

2. Ядро/рамы — сталь TFMG (уже через тег) + нетер-сталь Big Cannons.
3. Уран и торий — **убрать из Overworld** (biome modifier) и оставить только на Луне/астероидах или в Otherside — уран = космическая экспедиция.
4. Убрать путь «сырьё из булыжника».
5. Урезать тепло/выход (`uraniumHeatRatio` и т.д.) так, чтобы реактор T3 был сильнее паровых машин в разы, но не на порядки.
6. Расплавление и радиация — **включены**: риск — часть эндгейма.
7. Свинец — объединить с TFMG (одна система, как со сталью).
