# «Бесплатные» механики: что даёт энергию или ресурсы даром

Дата: 2026-11-06. Цель: в сборке не должно быть способов получать энергию, ресурсы или работу **без затрат ресурсов/энергии**.
Источники: поиск по классам и lang/recipe-файлам всех установленных jar + описания на Modrinth. Конфиги Create/TFMG ещё не сгенерированы — значения проверим после первого запуска.

Легенда: 🔴 даром навсегда · 🟠 почти даром / дёшево · 🟢 нормально (тратит ресурсы)

## 1. Источники вращения (SU)

| Источник | Мод | Статус | Что предлагаю |
|---|---|---|---|
| Water Wheel / Large Water Wheel | Create | 🔴 Работает от 1 блока текущей воды, навсегда | **Create: Picky Wheels** — колёса работают только в **речном биоме** у большого водоёма (как Hose Pulley); + урезать мощность в конфиге Create (`stressValues`) |
| Windmill Bearing | Create | 🔴 Ветер даром навсегда (в т.ч. **на корабле** — бесплатная тяга) | Picky Wheels: нужна открытая площадь, только Overworld; + урезать мощность; на кораблях — проверить и запретить при необходимости |
| Hand Crank | Create | 🟢 Тратит голод игрока | Оставить |
| Steam Engine | Create | 🟠 Нужна вода + тепло. Тепло может быть **пассивным** (лава/огонь/костёр под котлом) — даром навсегда | **Create: Low-Heated** — отключает пассивный нагрев, добавляет Basic Burner на твёрдом топливе |
| Blaze Burner без топлива | Create | 🟠 Даёт пассивный нагрев | Low-Heated отключает |
| Portable Engine | Simulated | 🟢 Топливо | Оставить |
| Stirling Engine | Create Propulsion | 🟢 Топливо | Проверить расход |
| Двигатели TFMG (малые, большой, турбина) | TFMG | 🟢 Топливо (бензин/дизель/керосин) | Проверить, откуда нефть (см. п. 3) |
| Industrial Motor | Gadgets & Gizmos | 🟢 FE → SU | См. FE |
| Kinetic Battery / Torsion Spring / Flywheel Bearing | Create Connected / Simulated / Bits 'n' Bobs | 🟢 Хранят энергию, не создают | Оставить |
| Creative Motor / Creative Cogwheel | Create / Create Encased | — Только креатив | — |

## 2. FE — найдены лишние дешёвые конвертеры

| Блок | Мод | Статус |
|---|---|---|
| **Industrial Alternator** (SU → FE) | Gadgets & Gizmos (`createthrusters`) | 🔴 Рецепт дешёвый: медный корпус, промышленное железо, вал, золото, редстоун. С бесплатным колесом = бесплатный FE |
| Industrial Motor (FE → SU) | Gadgets & Gizmos | 🟠 Дешёвый |
| Cable Insulator в режиме FE | TFMG | 🟠 Дешёвый (см. decisions.md) |
| Coral Generator (коралловая жидкость → FE) | Create Propulsion | 🟢 Жидкость = блейз-порошок + редстоун. Ресурсы тратятся |

→ Решение по FE должно закрыть **все три** конвертера, иначе дорогой останется только один из них.

## 3. Бесконечные ресурсы

| Механика | Мод | Статус | Что предлагаю |
|---|---|---|---|
| Hose Pulley из большого водоёма (≥10000 блоков) — бесконечная жидкость | Create | 🔴 Вода из океана — нормально; **лава из озёр Незера — бесконечное топливо** | Конфиг `hosePulleyBlockThreshold` поднять / для лавы запретить; или оставить только воду |
| Генераторы булыжника/камня | Create Cobblestone, Easy Stone Generators | 🔴 Бесконечный камень за SU → дробление → гравий → промывка → **железо/золото/цинк** | Удалить оба мода, или оставить с дорогими рецептами и убрать выход руды из промывки |
| Промывка гравия/песка вентилятором | Create | 🟠 Из бесконечного камня — самородки | Урезать шансы KubeJS |
| Обжиг/копчение вентилятором через лаву/огонь | Create | ✅ Закрыто модом Create Catalyst Wear: катализаторы изнашиваются под потоком | — |
| Lava + honey/chocolate → известняк/скория | Create | 🟢 Тратит мёд/шоколад | Оставить |
| Месторождения Rock & Stone | Create: Rock & Stone | 🔴 По умолчанию бесконечные | Включить «finite deposits» |
| Нефть TFMG (pumpjack) | TFMG | ❓ Нужно проверить, бесконечны ли залежи | Проверить конфиг |
| Сдвиг спавнера контрапцией | Create | 🟠 Ферма мобов из найденного спавнера в любом месте | Конфиг `spawnerMovement` → запретить |
| Деплоер с мечом | Create | 🟢 Тратит прочность | Оставить |

## 5. Вода: бесконечные источники

| Вариант | Что делает | Плюсы | Минусы |
|---|---|---|---|
| A. Оставить как есть | Ванильные 2×2 источники | Ничего не ломается | Вода есть везде даром |
| **B. Toffel's Finite Water** | Новые источники не создаются нигде, **кроме океанов/рек/пляжей** (настраивается) | Вода — ресурс места: база у реки, в пустыне/космосе её надо возить на корабле. Простой и лёгкий мод | Обновлялся в 12.2024 (но мод маленький); Hose Pulley из океана всё ещё бесконечен — это ок |
| C. Finite Water (LobsterMods) | Новые источники не создаются **нигде**, даже в океане остаются дыры | Максимально жёстко | Ломает фермы, бетон, промывку; Hose Pulley Create всё равно бесконечен из больших водоёмов |
| D. Flowing Fluids | Реалистичная физика жидкостей, почти всё конечно, интеграция с водяными колёсами (режим FLOW) | Очень атмосферно | **Ранняя разработка** (автор предупреждает), риски с трубами Create, Sable, производительностью |
| Доп.: Dynamic Waters | Реальные течения рек, корабли Sable дрейфуют по течению | Классно для путешествий | Свой генератор рек — проверить совместимость с Tectonic/Terralith |

**Решено (2026-11-06):** Toffel's Finite Water + Picky Wheels + Low-Heated установлены; генераторы камня убраны; поезда на топливе, конечные залежи Rock & Stone и запрет переноса спавнеров — после генерации конфигов. Итог — в `decisions.md`.
